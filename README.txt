PRO-IQ + CLOUDWISE HTML PROJECT

FILES
- index.html: redirects to the Pro-IQ home page
- pro-iq.html: Pro-IQ main website and HR dashboard
- who-caused-it.html: CloudWise “Who caused it?” page
- cloudwise.html: CloudWise dashboard with Stop the loss and Hidden expenses sections

RUN WITH VS CODE LIVE SERVER
1. Extract this ZIP to a folder.
2. Open that folder in Visual Studio Code (File > Open Folder).
3. Install the “Live Server” extension if it is not installed.
4. Right-click index.html and choose “Open with Live Server”.
5. Use the website navigation to move between pages. Keep all HTML files in the same folder.

This is a static HTML/CSS/JavaScript demo. Live Server runs it locally; it does not publish it to the internet or provide a backend/database.
